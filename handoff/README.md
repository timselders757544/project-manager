# Handoff

Hier legt Claude chat zijn conclusies neer voor Claude Code.

- Eén bestand per handoff, met de datum voorop: JJJJ-MM-DD-onderwerp.md.
- Claude Code leest de nieuwste handoff en voert hem uit.
- Is hij verwerkt, dan zet Claude Code bovenaan: Verwerkt op JJJJ-MM-DD, met wat er gedaan is.
- Handoffs blijven staan. Samen vormen ze de geschiedenis van wat in chat is besloten.
